# Что можно вернуть навык

Полный перечень элементов ответа — тех, что действительно работают, с точными лимитами.
Источники в [12-sources.md](12-sources.md).

## Коротко: элементов восемь

| Элемент | Что это |
|---|---|
| `response.text` | текст, который показывается и озвучивается |
| `response.tts` | текст для озвучивания, можно с разметкой звуков |
| `response.card` | визуальная карточка — **на Станции не отображается** |
| `response.buttons` | кнопки — **на Станции не отображаются** |
| `response.end_session` | **обязательное поле**: завершить ли сессию |
| `response.directives` | платформенные директивы, сейчас описана одна |
| `response.show_item_meta` | метаданные утреннего шоу |
| `response.analytics` | события для AppMetrica |

Многое из того, что встречается в старых руководствах и в обсуждениях, в протокола **нет**:
`suggest`, `smartResponse`, `endOfTurn`, `markdown`, `media_state`, `photos`, `snippets`,
`dynamic_image_spec`, `subtitle`, `blocks`, `image.url`, `ScrollCard`, `SmallCard`. Список с
обоснованием — в [02-protocol-reference.md](02-protocol-reference.md), в последней таблице.

## Минимальный ответ

```json
{
  "response": {
    "text": "Открываю браузер.",
    "end_session": false
  },
  "version": "1.0"
}
```

Два обязательных поля: `response` и `version`. Внутри `response` обязательно `end_session`
(даже если `false`). `text` обязательно, но может быть пустой строкой — если заполнен `tts`.

## `response.text`

Максимум **1024 символа**. Это и то, что показывается, и то, что Алиса произносит, если не
смогла отобразить карточку.

Цитата из документации, которая объясняет поведение на Станции:

> Текст также используется, если у Алисы не получилось отобразить включенную в ответ карточку.
> **На устройствах, которые поддерживают только голосовое общение с навыком, это будет
> происходить каждый раз, когда навык присылает карточку в ответе.**

То есть на Станции карточка не «иногда не показывается» — она не показывается **никогда**, и
озвучивается всегда `text`. Подробности — [05-station-and-activation.md](05-station-and-activation.md).

Символ новой строки доступен как `\n`. Длинный текст — плохая идея: 1024 символа это примерно
полторы минуты чтения вслух.

## `response.tts`

Максимум **1024 символа**. Теги `<speaker>` в лимит **не входят** — можно вставить ссылку на
аудиофайл, не тратя квоту.

Разметка внутри `tts`:

| Разметка | Что делает |
|---|---|
| `сло+во` | логическое ударение |
| `sil <[1500]>` | пауза в миллисекундах |
| `word <[с и м е т о]> phonemes` | произношение слова пофонемно |
| Пробел после знака препинания | пауза 50–100 мс |

Подробнее, включая голоса, — [06-scripts-and-voice.md](06-scripts-and-voice.md).

**Практика:** если `tts` не заполнен, Алиса произносит `text`. Если заполнен — произносит `tts`.
Для R2D2, где текст отвечается голосом и содержит результат работы LLM, разница существенна:
если в тексте есть числа, даты или названия, их нужно разметить, иначе Алиса прочитает неверно.

## `response.buttons`

```json
"buttons": [
  {
    "title": "Открыть",
    "url": "https://example.com/page",
    "payload": { "action": "open" },
    "hide": false
  }
]
```

| Поле | Лимит | Комментарий |
|---|---|---|
| `title` | **64 символа**, **обязательное** | эмодзи допустимы |
| `url` | 1024 байта | |
| `payload` | 4096 байт | объект |
| `hide` | булево, по умолчанию `false` | |

Руководство по интерфейсу даёт отдельную рекомендацию: **не более 6 кнопок в одном «бабле»**.
Это дизайнерское указание, а не жёсткий протокольный лимит; в справочнике API ограничения
на количество кнопок нет вообще.

> На устройствах с экраном вы можете предоставить пользователю дополнительные возможности
> и, при необходимости, разные сценарии работы.

**Кнопки — только для устройств с экраном.** На Станции они бессмысленны.

### Как работает `hide` — самая неочевидная механика

Отсюда же и то, что нажатие на кнопку даёт **два разных типа запроса**:

| Ситуация | `request.type` |
|---|---|
| пользователь сказал фразу | `SimpleUtterance` |
| нажата кнопка с `hide: false` | `SimpleUtterance` |
| нажата **отдельная** кнопка (`hide: true`) с **пустым** `payload` | `SimpleUtterance` |
| нажата **отдельная** кнопка (`hide: true`) с **непустым** `payload` | `ButtonPressed` |
| нажат элемент карточки с непустым `payload` | `ButtonPressed` |
| первый контакт в сессии | `SimpleUtterance` (поля пустые) |

`hide: false` означает «кнопка останется в истории диалога» (показывается как «бабл»).
`hide: true` — «кнопка одноразовая, в историю не попадёт».

## `response.card`

Три типа. Все картинки — **загруженные**, по `image_id`, а не по URL.

> ⚠️ **Яндекс не запрашивает ваши изображения по HTTP.** Поле `card.image.url` не существует.
> Картинку нужно загрузить через API и сослаться на результат.

```json
"card": { "type": "BigImage", "image_id": "<ваш-skill-id>/<хэш>", "title": "..." }
```

| Параметр | `BigImage` | `ItemsList` | `ImageGallery` |
|---|---|---|---|
| `image_id` | ✅ | у элемента | у элемента |
| `title` | ≤ 128 | ≤ 128 у элемента | ≤ 128 у элемента |
| `description` | ≤ 1024 | ≤ 256 у элемента | — |
| `header.text` | — | ≤ 64, обязателен если объект есть | — |
| `footer.text` | — | ≤ 64, обязателен если объект есть | — |
| элементов | — | **1–5** | **1–7 или 1–10** ⚠️ |
| `button` | ✅ | ✅ у элемента | ✅ у элемента |

### Семантика кнопки карточки

- `button` **отсутствует** → Диалоги использует `card.title` как команду;
- `button.text` равен `""` → команда приходит пустой.

Это неочевидно и стоит помнить: если не задать кнопку, нажатие на карточку всё равно что-то
отправит.

### Размеры картинок

Из руководства по интерфейсу (для приложения Яндекса):

| Тип | 1x | 1.5x | 2x | 3x | 3.5x | 4x |
|---|---|---|---|---|---|---|
| `BigImage` | 388×172 | 582×258 | 776×344 | 1164×516 | 1358×602 | 1552×688 |
| элемент списка | 60×60 | 90×90 | 120×120 | 180×180 | 210×210 | 240×240 |
| `ImageGallery` | 328×480 | | | | | |

**Документация описывает интерфейс приложения, не Станции.** Отдельной таблицы размеров под
Станцию нет, потому что Станция карточки не рисует.

### Три типа интерфейса, как их видит платформа

| Тип | Что это | Примеры |
|---|---|---|
| GUI | графический | сайт, приложение, часы, ТВ |
| VUI | голосовой | **умные колонки Яндекса** |
| CUI | в приложении | Алиса в приложении Яндекса |

> Устройства, которые поддерживают только голосовое управление (например, **Яндекс Станция**),
> не смогут отобразить графические элементы.

## Загрузка изображений

| Параметр | Значение |
|---|---|
| Минимальный размер | 1 КБ |
| Максимальный размер | 1 МБ |
| Форматы | PNG, JPEG, GIF, BMP, TIFF, WEBP |
| Квота на аккаунт | 100 МБ |
| Формат `image_id` | `<skill-id или user-id>/<хэш>` |
| При превышении квоты | HTTP 429 |

Изображением можно управлять и по HTTP — картинку можно генерировать в рантайме. Механизм описан
в `resource-upload`.

## Аудио

**Аудио — не отдельное поле ответа.** Оно встраивается в `tts`:

```
<speaker audio="dialogs-upload/<ваш-skill-id>/<audio-id>.opus">
```

| Параметр | Значение |
|---|---|
| Длительность | до 120 секунд, обрезается автоматически |
| Размер файла | до 5 МБ |
| Форматы на загрузке | MP3, WAV, OGG |
| Квота на аккаунт | 1 ГБ (считается в сжатом виде, уже в Opus) |
| Теги в лимите `tts` | не считаются |

Плюс библиотека готовых звуков — подключается так же.

Ранее существовал `directives.audio_player` для потокового аудио по URL, и тип запроса
`AudioPlayer`. **В текущей документации их нет.** Если они ещё работают — это не документировано
и не является контрактом.

## `response.directives`

```json
"directives": {
  "start_account_linking": {}
}
```

**Документирована ровно одна директива** — `start_account_linking`, она запускает связку
аккаунтов. Остальные (`audio_player`, `start_purchase`, `confirm_purchase`) были в документации
до 2022 года и убраны; упоминаний о них в текущей версии нет.

## `response.show_item_meta`

Только для утреннего шоу (`Show.Pull` / `MORNING`). Поля: `content_id`, `title`, `title_tts`,
`publication_date`, `expiration_date`.

В режиме шоу карточка и кнопки **не показываются**, изменения состояния игнорируются — чтобы
показ не превращался в разговор.

## `response.analytics`

```json
"analytics": {
  "events": [
    { "name": "skill-start", "value": { "source": "station" } }
  ]
}
```

`name` обязательное, `value` — объект с глубиной вложенности не более 5 уровней. Требует
включённого AppMetrica.

## Смерть сессии

`response.end_session: true` завершает сессию навыка. Также сессия завершается сама, если
навык:

- прислал ответ, не соответствующий формату;
- не успел ответить за 4,5 секунды.

## Минимальный набор для голоса

Если навык работает только голосом (как R2D2), разумный ответ — тот же, что в примере выше:
`text`, `end_session`, `version`. Карточки, кнопки и медиа — это для устройств с экраном, а
для Станции они просто не будут отображены, при этом будут съедать часть лимита в 5000 символов.
