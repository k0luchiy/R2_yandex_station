# Платформа Яндекс Диалогов — справочник

Это папка **о самой платформе Алисы**, а не о R2D2. Все файлы `docs/` уровнем выше описывают
*этот проект*: его архитектуру, бэкенды, бюджет задержки, безопасность. Здесь — про то, что
навык вообще из себя представляет, какие у него поля, лимиты и правила публикации.

Оба набора документов нужны одновременно: R2D2 — это реализация навыка, и почти каждое её
решение упирается в ограничение платформы. Здесь эти ограничения записаны.

## Пять вещей, которые нужно знать до всего остального

1. **Таймаут ответа — 4,5 секунды.** Это включает установку соединения, доставку запроса, вашу
   работу и доставку ответа. Не «на работу», а целиком. Подробнее — [07](07-hosting-and-webhook.md).
2. **Весь ответ — не больше 5000 символов.** `text` и `tts` — по 1024 каждое. Остальное — карточки,
   кнопки, директивы.
3. **Яндекс Станция — поверхность без экрана.** Картинка и кнопки в ответе не показываются;
   Алиса озвучивает `response.text`. Подробнее — [05](05-station-and-activation.md).
4. **Приватный навык — это полноценный навык.** Он проходит автомодерацию, доступен только вам,
   и работает на Станции, привязанной к вашему же аккаунту. Публиковать в каталог не нужно.
5. **Объём всего ответа ограничен 5000 символами, и это не «1024 на текст».** Ошибка в этом
   числе — самая частая причина молчаливого отказа.

## Легенда достоверности

Каждое утверждение в этих файлах помечено уровнем доверия. Это существенно: Яндекс
документирует меньше, чем разработчики выясняют на практике, и часть «общеизвестного» —
вневремя правда.

| Пометка | Что означает |
|---|---|
| **официально** | Прямая цитата из документации Яндекса. Ссылка в [12-sources.md](12-sources.md) |
| **замерено** | Измерено на практике или прочитывается в коде открытых реализаций |
| **практики** | Наблюдение разработчиков; может устареть, приводится со ссылкой |
| **устарело** | Так было, больше не работает. Не использовать |

Утверждения без пометки — это вывод из совокупности источников.

## Как читать официальную документацию

Документация Яндекс Диалогов собрана генератором Diplodoc и **отдаёт исходный Markdown**:
достаточно дописать `.md` к адресу страницы.

```bash
# обычная страница целиком, без рендеринга и без JS
curl -s https://yandex.ru/dev/dialogs/alice/doc/ru/response.md

# полный список страниц (85 штук)
curl -s https://yandex.ru/dev/dialogs/alice/doc/sitemap.xml
```

Рекомендуемый `llms.txt` по адресу `.../doc/ru/llms.txt` **отдаёт 404** — не тратьте время.
Включаемые блоки (`{% include %}`) в `.md` не раскрываются, они есть только в отрендеренном
HTML, поэтому цитаты про таймаут брались из рендера.

## Как это соотносится с кодом R2D2

R2D2 реализует подмножество протокола, достаточное для голосового шлюза. Проверено по коду:
`core/render.py` возвращает `response.text` / `response.tts` / `response.end_session` и
`version: "1.0"`, обрезая текст до 1024 символов; `core/brain.py` читает `request.command`,
`request.original_utterance`, `session.new` и `session.application.application_id`; проверка
доступа — по `session.skill_id` и `session.user.user_id`. Все лимиты, которые код соблюдает,
совпадают с документацией.

Что R2D2 **сознательно не делает** и почему — [11-pitfalls-and-recipes.md](11-pitfalls-and-recipes.md).
