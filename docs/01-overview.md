# R2D2 — умный навык Алисы для Яндекс Станции

## Идея

Домашняя Яндекс Станция (Лайт) умеет только то, что умеет базовая Алиса. Мы
создаём навык **R2D2** — «прокси-мозг», который даёт Алисе доступ к более
сильному LLM и к инструментам (скиллам), работающим на локальном ноутбуке.

Пользователь обращается к Алисе:

```
— Алиса, запусти навык R2D2
— Попроси R2 открыть браузер
— R2, отправь в телеграм сводку новых статей про LLM с arxiv
```

Дальше Алиса отправляет запрос на наш сервер, сервер решает его с помощью LLM,
при необходимости выполняет действия (управление ноутбуком, отправка в
Telegram, поиск по arxiv) и возвращает короткий голосовой ответ.

## Цели

1. Дать Алисе «более умный» мозг (сильный LLM вместо базовой Алисы).
2. Дать Алисе доступ к ноутбуку: статус системы, приложения, произвольные
   команды (с подтверждением рискованных).
3. Дать Алисе канал отправки контента в Telegram (сводки, отчёты, длинные
   тексты, которые неудобно зачитывать вслух).
4. Укладываться в жёсткие ограничения Алисы: ответ за **4,5 секунды**,
   максимум **1024 символа** текста/tts.

## Принцип

```
Яндекс Станция (Лайт)
        │  голос: «Алиса, попроси R2 ...»
        ▼
Яндекс.Диалоги (платформа Алисы)
        │  HTTPS POST /webhook (JSON)
        ▼
cloudflared-туннель (публичный постоянный URL, валидный HTTPS)
        ▼
Локальный сервер на ноутбуке (FastAPI)
        │
        ├─ /webhook        — обработчик запросов Алисы
        ├─ /health         — проверка работоспособности
        ├─ Brain (LLM)     — OpenRouter | YandexGPT (переключатель)
        ├─ Tools           — лаптоп, Telegram, arxiv, web search
        ├─ Async worker    — долгие задачи (сводки → в Telegram)
        └─ SQLite          — память диалогов и состояние
```

## Сценарии использования (MVP)

| Сценарий | Как выглядит | Механизм |
|---|---|---|
| Вопрос | «R2, что такое квантовые точки?» | Один вызов LLM → короткий ответ |
| Быстрое действие | «R2, открой браузер» / «пришли на зарядку статус ноутбука в телегу» | Вызов инструмента + `spoken_reply` |
| Рискованная команда | «R2, удали папку tmp» | Запрос подтверждения голосом |
| Долгая задача | «R2, отправь сводку статей про LLM с arxiv» | Мгновенный ответ + фоновая задача → результат в Telegram |

## Не-цели (на этом этапе)

- Публикация в каталог навыков (работаем как приватный навык только для себя).
- Полноценный «умный дом» (управление устройствами через Яндекс IoT) — может
  быть расширением позже.
- Мультипользовательский доступ.

## Технологический стек

- **Сервер:** Python 3.11+ / FastAPI / uvicorn.
- **LLM:** OpenAI-совместимый SDK (`openai`) поверх OpenRouter или YandexGPT.
- **Туннель:** cloudflared (named tunnel, бесплатно).
- **База:** SQLite (стандартная библиотека + `aiosqlite`).
- **Telegram:** Bot API (бот из BotFather), `httpx`.
- **Управление лаптопом:** Linux-команды (subprocess), статус через `/proc`/`psutil`.
