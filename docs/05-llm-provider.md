# Мозг R2D2: бэкенды, промпты, function calling

> **Актуальность документа.** R2D2 больше не выбирает провайдера сам. Каждый ход
> сначала идёт в **постоянную сессию opencode**; цепочка HTTP-провайдеров —
> запасной путь на случай, если opencode-сервер недоступен. Полное описание
> первичного пути — в [11-opencode-backend.md](11-opencode-backend.md).

## 1. Как выбирается бэкенд

Никакого `LLM_PROVIDER=openrouter|yandexgpt` больше нет. Набор бэкендов и
порядок их использования задаёт **один файл** — `config/backends.json`:

```json
{
  "chain": ["opencode", "zen", "yandexgpt", "openrouter"],
  "backends": [
    {"name": "opencode", "kind": "opencode_session", "base_url": "http://127.0.0.1:4599",
     "username": "${R2D2_OC_USERNAME}", "password": "${R2D2_OC_PASSWORD}",
     "voice_agent": "r2d2-voice", "task_agent": "r2d2-agent",
     "fast_model": "opencode/space-bunny-free", "task_model": "opencode/space-bunny-free",
     "summarize_model": "opencode/space-bunny-free", "timeout": 3.2},
    {"name": "zen", "kind": "openai_compatible", "base_url": "https://opencode.ai/zen/v1",
     "api_key": "${R2D2_ZEN_KEY}", "model": "space-bunny-free", "auth_style": "bearer"},
    {"name": "openrouter", "kind": "openai_compatible", "base_url": "https://openrouter.ai/api/v1",
     "api_key": "${OPENROUTER_API_KEY}", "model": "inclusionai/ling-3.0-flash-sante:free", "auth_style": "bearer"},
    {"name": "yandexgpt", "kind": "openai_compatible",
     "base_url": "https://llm.api.cloud.yandex.net/foundationModels/v1",
     "api_key": "${YANDEX_API_KEY}", "model": "gpt://${YANDEX_FOLDER_ID}/yandexgpt-lite-5",
     "auth_style": "yandex", "auth_mode": "api_key"}
  ]
}
```

Как это работает:

- **`chain`** — порядок. `opencode` стоит первым, но это **маршрут, а не член
  цепочки**: попытка по нему уже была, и второй заход на тот же хост съел бы
  бюджет, которого у хода больше нет. Реальная цепочка фолбэков — `zen`,
  `yandexgpt`, `openrouter`.
- **`kind`** — единственное, что знает код: `kind` → конструктор. Сейчас их
  два: `opencode_session` (сессия opencode за обычным интерфейсом) и
  `openai_compatible` (один клиент на все OpenAI-совместимые API).
- **`${VAR}`** подставляется из окружения за один проход. Нет переменной в
  поле-учётке → поле пустое, WARNING с **именем** переменной, бэкенд выпадает
  из цепочки с причиной. Нет переменной в другом поле → ошибка разбора.
- **Ретраев «на том же» нет.** Ошибка или таймаут переходят к *следующему*
  бэкенду, потому что дедлайн общий на ход, а повтор на том же хосте съел бы
  бюджет. Внутри одного OpenAI-совместимого клиента есть один ретрай на
  429/502/503 с паузой 0,4 с.

### 1.1 Отказ — это не пустой ответ

Общий инвариант всех бэкендов, а не только opencode: **HTTP 200 не является
успехом**. Отказ модели лежит в теле ответа, поэтому бэкенд, получивший 200 с
непустым `error`, поднимает `BackendErrorEnvelope` вместо того, чтобы вернуть
`Choice`. Ответ, который нельзя произнести, должен выглядеть как ошибка, иначе
пользователь услышит текст об отказе и не отличит его от ответа.

## 2. Почему ушли с бесплатных моделей OpenRouter

Это не каприз, а замер. Бесплатные модели OpenRouter давали разброс задержки
1–12 с и регулярные 429/502, что не помещается в бюджет Алисы (4,5 с); часть
из них отдавала «сырые рассуждения» на английском вместо ответа. Для голосового
ассистента это означало либо молчание, либо чтение вслух потока рассуждений.

Переход на opencode добавил вторую, более неприятную находку: через
`opencode serve` **все** бесплатные Zen-модели, кроме одной, отклоняются
внутренним 403, а платные — внутренним 402. Полная таблица замера и выводы — в
[11-opencode-backend.md](11-opencode-backend.md), раздел 9. Практическое
следствие: **сильной модели сейчас нет вообще**, и в трёх слотах
(`fast_model`, `task_model`, `summarize_model`) стоит один и тот же
идентификатор. Пополнение баланса Zen меняет три строки и больше ничего.

Поэтому рекомендации вида «возьми бесплатную `:free`-модель» здесь больше не
работают, и в таблице фолбэков модели указаны явно, а не «выбери что хочешь».
Но и «бесплатных моделей нет» было бы неправдой: ниже — свежий свип, а не
пересказ старого замера.

### 2.1 Свип бесплатных моделей OpenRouter: 26.09.2026

Из 17 идентификаторов, которые `GET /models` отдаёт с бесплатным тарифом,
**отвечает один**: `inclusionai/ling-3.0-flash-sante:free`, 9 проб из 9,
0,84–4,35 с. Остальные шестнадцать либо отклоняются (HTTP 429, 403, 502), либо
**молчат**: HTTP 200 с пустым `content`, потому что модель потратила бюджет
токенов на рассуждение. Для голосового ассистента молчание равно отказу, поэтому
в конфигурацию попал ответчик, а не «любая `:free`-строка».

Прежний идентификатор `inclusionai/ling-3.0-flash:free` был в `config/backends.json`
и **молчал**: HTTP 404, `This model is unavailable for free`. Ни один структурный
тест этого не видел — запись была корректной, а провайдер её не обслуживал.
Теперь измеренный свип лежит в `tests/test_backend_registry.py` и проверяется
тестом, который падает, как только настроенный идентификатор начинает
не отвечать; полный протокол с задержками и формулировками провайдера — в
[qa/d8-openrouter-probe.md](../qa/d8-openrouter-probe.md).

Три оговорки, из-за которых `openrouter` остаётся «последним резервом», а не
вторым мозгом:

* **бесплатный тариф ограничен 50 запросами в сутки** на этом ключе
  (`free-models-per-day`, `X-RateLimit-Limit: 50`, измерено 26.09.2026);
  исчерпанный лимит — HTTP 429, а не деградация;
* **свободный идентификатор исчезает без предупреждения** — так и случилось с
  предыдущим;
* **длинный ответ в голосовой бюджет не помещается**: короткий вопрос
  0,84–1,85 с — влезает в `r2d2_fast_deadline` = 3,2 с, а сводка на 1200 токенов
  (4,0–4,4 с) уже нет. Фолбэк годится для короткого ответа и не годится для
  длинного.

## 3. Состав цепочки фолбэков и их цена

| Имя | Адрес | Модель | Когда нужен |
|---|---|---|---|
| `zen` | `https://opencode.ai/zen/v1` | `space-bunny-free` | opencode-сервер поднят, но ход не прошёл (503, таймаут, отказ модели) |
| `yandexgpt` | `https://llm.api.cloud.yandex.net/foundationModels/v1` | `gpt://<folder>/yandexgpt-lite-5` | Zen недоступен; серверы в РФ, низкая задержка |
| `openrouter` | `https://openrouter.ai/api/v1` | `inclusionai/ling-3.0-flash-sante:free` | последний резерв; единственная из 17 бесплатных, ответившая на все пробы (26.09.2026), поэтому самая капризная |

Различия между ними — **схема авторизации**, а не разный код:
`auth_style: "bearer"` шлёт `Authorization: Bearer <api_key>`, `auth_style:
"yandex"` шлёт `Api-Key <api_key>` (или `Bearer <iam_token>`, если
`auth_mode: iam_token`).

## 4. Единый интерфейс бэкенда

```python
@runtime_checkable
class Backend(Protocol):
    name: str

    async def complete(
        self,
        messages: Sequence[ChatMessage],
        tools: Sequence[ToolSchema] | None = None,
        *,
        max_tokens: int = 400,
        temperature: float = 0.7,
        timeout: float = 3.0,
        model: str | None = None,
    ) -> Choice: ...

    async def aclose(self) -> None: ...
```

- Структурный протокол, а не ABC: бэкенд не наследуется, а собирается из
  конфигурации, поэтому наследование и не нужно.
- `Choice` содержит `content`, `tool_calls[]`, `provider`, `model`, `raw`.
- Вызывающий код ветвится на **одном** корне ошибок (`BackendError`) и на
  `httpx.TimeoutException` отдельно: таймаут означает «у хода больше нет
  бюджета», и на него повторять нельзя.
- У `opencode_session` параметры `tools`, `max_tokens`, `temperature`
  принимаются и игнорируются: сессия уже держит разговор, а единственное место,
  где может жить решение об инструменте, — `permission` агента. `tool_calls` у
  этого бэкенда всегда пуст.

## 5. System-промпт цепочки фолбэков

На первичном пути системный промпт живёт в определении агента
`r2d2-voice` в `config/opencode/r2d2.opencode.json` (версионируется рядом с его
же `permission`). Для фолбэка, где агента нет, промпт остаётся в коде — и это
ядро поведения, потому что его текст Алиса читает вслух:

```
Ты — R2D2, голосовой ассистент в Яндекс Станции. Твои ответы Алиса зачитывает ВСЛУХ.
Правила:
1. Отвечай ОЧЕНЬ КРАТКО: 1–3 коротких предложения, как живой человек.
2. Никогда не используй markdown, смайлики, эмодзи, звёздочки, скобки-кавычки,
   спецсимволы — только обычный текст.
3. Не выводи ссылки, длинные списки и большие числа вслух.
4. Если контент длинный (сводка, отчёт, статья, список) — НЕ зачитывай его.
   Используй инструмент отправки в Telegram и подтверди одной фразой:
   «Отправил в телеграм».
5. На обычные вопросы отвечай САМ, без инструментов. Инструменты вызывай ТОЛЬКО когда
   пользователь явно просит действие. Не угадывай запрос — используй слова
   пользователя дословно.
6. Если нужно действие — вызови инструмент. В аргументах ОБЯЗАТЕЛЬНО укажи поле
   spoken_reply: короткую фразу, которую пользователь услышит сразу.
7. Опасные команды (удаление, перезагрузка, sudo, изменение системы) — сначала
   вызови confirm_risky_action и спроси: «Подтверди: действие?». Выполняй только
   после явного «да».
8. Не выдумывай факты. Не знаешь — так и скажи.
9. Ты общаешься только по-русски.
```

Пример хорошего ответа на вопрос «что такое квантовые точки»:
> «Это крошечные полупроводниковые частицы размером в несколько нанометров.
> Они светятся разными цветами в зависимости от размера — этим пользуются в
> экранах и медицине.»

Пример плохого (зачитывается вслух):
> «Квантовые точки — нанокристаллы... Далее: https://ru.wikipedia.org/... — слишком длинно, есть ссылка, markdown.»

## 6. Function calling на цепочке фолбэков

Tools передаются в OpenAI-совместимом формате:

```json
{
  "type": "function",
  "function": {
    "name": "tg_send",
    "description": "Отправить сообщение в личный телеграм пользователя. Для длинного контента и отчётов.",
    "parameters": {
      "type": "object",
      "properties": {
        "text": { "type": "string", "description": "Текст сообщения" },
        "spoken_reply": { "type": "string", "description": "Короткая фраза для озвучки, напр. «Отправил в телеграм»" }
      },
      "required": ["text", "spoken_reply"]
    }
  }
}
```

**Ключевой приём `spoken_reply`:** модель при вызове инструмента сразу пишет
фразу для озвучки. Мы выполняем инструмент и возвращаем эту фразу без второго
раунда LLM — это экономит 0,5–1,5 с. На первичном пути этот приём не нужен:
голосовой агент отвечает текстом, а не вызовом инструмента, и длинный контент
уходит в Telegram по сентинелу эскалации.

Если `tool_calls` пуст → озвучиваем `content` (с обрезкой до 1024 симв. и
очисткой от markdown).

## 7. Как поменять модель

Три строки в `config/backends.json`, больше нигде — ни в коде, ни в конфиге
агентов. Перед перезапуском новый идентификатор проверяется против каталога
сервера: **неизвестный `model id` — не ошибка**, opencode молча подставит другую
модель и ответит 200, а R2D2 ответил бы голосом от мозга, который никто не
выбирал.

## 8. Ограничение токенов и история

- `max_tokens`: 300–400 для голосовых ответов (обычно достаточно 1–3 фраз).
- История: последние ~20 сообщений, длинные реплики ужимаются. Она нужна
  **только** цепочке фолбэков: сессионному пути история не передаётся, её уже
  держит opencode.

## 9. Измерение скорости

Каждый ход пишет одну строку с `route` и `path` (см.
[07-latency-strategy.md](07-latency-strategy.md)). Целевые бюджеты:

| Этап | Бюджет |
|---|---|
| Распознавание + сеть Алисы | ~1.0–1.5 с (вне нашего контроля) |
| Туннель + наш сервер | ~0.1–0.3 с |
| Голосовой ход в сессии (p50 1.667 с, p95 2.247 с) | 0.5–2.3 с |
| Холодная сессия (первый ход) | 15.5–18.6 с — всегда в фоне |
| Исполнение быстрого инструмента | 0.05–0.5 с |
| **Итого от нас на голосовом пути** | **< 3.2 с** |
