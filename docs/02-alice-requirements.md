# Ограничения и требования платформы Алисы

Документ собран из официальной документации Яндекс.Диалогов. Это «контракт»,
под который мы проектируем R2D2.

## 1. Что такое навык

Навык — это **HTTPS-веб-сервис** разработчика. Алиса при каждом обращении
шлёт на наш backend `POST`-запрос с JSON, а наш сервис возвращает JSON-ответ.

## 2. Таймаут: 4,5 секунды ⚠️

> Время ожидания ответа от навыка — 4,5 секунды. Если Диалоги не получат ответ
> в течение этого времени, сессия навыка завершится. Алиса сообщит
> пользователю, что навык не отвечает.

В 4,5 секунды входят:
- установка сетевого соединения;
- доставка запроса до нашего сервера;
- **время работы нашего сервера**;
- доставка ответа до серверов Алисы.

**Вывод:** наш код + вызов LLM должны укладываться примерно в 2–3 секунды,
чтобы оставался запас на сеть. См. [07-latency-strategy.md](07-latency-strategy.md).

## 3. Ограничения ответа

| Поле | Лимит | Комментарий |
|---|---|---|
| `text` | **1024 символа** | Показывается и озвучивается |
| `tts` | **1024 символа** | Теги звуков в лимит не входят |
| `buttons[].title` | 64 символа | — |
| `buttons[].url` | 1024 байта | — |
| `buttons[].payload` | 4096 байт | — |

- `text` может быть пустым, если заполнен `tts`.
- На устройствах без экрана (Яндекс Станция Лайт) графика не отображается —
  только голос. Поэтому дизайн ответа — **голосовой**.

**Вывод:** длинный контент (сводки, статьи) НЕ зачитываем — отправляем в
Telegram. Вслух — только короткое подтверждение.

## 4. HTTPS и публикация

- Webhook должен работать по **HTTPS**.
- Принимаются только **fullchain-сертификаты**; самоподписанные отвергаются
  («Некорректный SSL-сертификат»).
- Поэтому локальный сервер публикуем через **cloudflared** (валидный
  сертификат, постоянный URL). См. [08-deployment.md](08-deployment.md).
- После публикации Диалоги периодически проверяют навык (служебный запрос со
  словом `ping`). Если навык не отвечает несколько часов — его отключают.

## 5. Имя навыка и активация

- Название навыка — **2–5 слов** (или одно слово для уникального бренда).
  Нельзя использовать слова «Алиса», «Яндекс», «Станция».
- Активационные фразы:
  - «Алиса, запусти навык <имя>»
  - «Алиса, запусти чат с <имя>»
  - «Алиса, давай поиграем в <имя>»
  - «Алиса, скажи <имя> <команда>» / «спроси у <имя> <команда>» / «попроси <имя> <команда>»
- Можно задать **до 3 дополнительных активационных имён** (сокращения,
  словоформы, аббревиатуры).
- Незнакомые/выдуманные слова в имени Алиса может не распознать сразу; на
  «обучение» слову уходит 2–3 недели после публикации.

**Практика для R2D2:**
- Название навыка: `Р2Д2`.
- Активационные имена: пробуем короткие (`Р2`, `R2`, `Арту» — нет), в консоли
  будет видно, какие принимаются. Если «Р2»/«R2» не пройдут по минимальной
  длине, используем «Р2Д2» как имя и более длинные варианты активации.
- Конкретные значения выставляем в консоли разработчика и проверяем голосом.

## 6. Обязательные команды

Для модерации (даже приватный навык проходит автомодерацию) обязательны:

- «Помощь» — перечислить команды управления навыком.
- «Что ты умеешь» — бриф о возможностях.

**Вывод:** в коде обрабатываем эти фразы фиксированными краткими ответами,
не гоняя их через LLM.

## 7. Выход из навыка

Пользователь в любой момент может выйти: «Алиса, вернись», «Алиса, хватит»,
«Стоп», «Закончить», «Выйти». Наш сервер может выставить `end_session: true`.

## 8. Приватный навык (наш сценарий)

- **Приватный** навык доступен только владельцу (на всех поверхностях, где он
  авторизован своим Яндекс-аккаунтом).
- Приватные навыки проходят **автомодерацию** перед публикацией.
- Тестировать голосом можно **до** полной публикации: делаем навык приватным и
  называем Алисе активационное имя с колонки/телефона.
- Публиковать в каталог не обязательно.

**Вывод:** настраиваем тип доступа «Приватный», ждём автомодерацию (обычно
быстро) и пользуемся.

## 9. Надёжность

- «На каждые 10 обращений допускается лишь 1 ошибка сервера» — добавляем
  ретраи к LLM-провайдеру и аварийные ответы.
