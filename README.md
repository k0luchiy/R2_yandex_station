# R2D2 — умный навык Алисы для Яндекс Станции

Навык, который даёт Алисе на Яндекс Станции «более умный мозг» (сильный LLM
через OpenRouter или YandexGPT) и доступ к инструментам на твоём ноутбуке:
управление системой, произвольные команды с подтверждением рискованных, и
отправка длинного контента в Telegram.

```
«Алиса, запусти навык Р2Д2»
«Р2, отправь в телеграм сводку статей про LLM с arxiv»
«Р2, какой заряд у ноутбука?»
«Р2, открой браузер»
```

## Ключевые идеи

- **Протокол Алисы:** webhook + JSON, таймаут **4,5 с**, ответ ≤ **1024 символа**.
- **Скорость:** один раунд LLM + `spoken_reply` в аргументах инструмента →
  мгновенный голосовой ответ; долгие задачи (сводки) — в фоне, результат в Telegram.
- **Приватный навык:** доступен только тебе, автомодерация.
- **Безопасность:** whitelist по `skill_id`/`user_id`, классификация команд,
  рискованные — только с голосовым подтверждением.

## Стек

Python 3.11+ · FastAPI · OpenAI-совместимый SDK · OpenRouter / YandexGPT ·
SQLite · cloudflared · Telegram Bot API · Linux
